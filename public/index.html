Phone widget and shortcuts

Three ways to use Chronos on your phone without digging through tabs.

1. Install the app

Open this site in Chrome on your phone, tap ⋮ → Add to Home screen (or Install app). Chronos gets its own icon and opens full-screen.

2. Long-press shortcuts

Long-press the Chronos icon for Log today (opens today's entry in the Notion app, creating it if needed) and This week. Drag either one to your home screen for a one-tap button.

3. Home-screen widget

Install KWGT Kustom Widget Maker (by Kustom Industries) from the Play Store. Add a KWGT widget, add an Image item, set its Mode to Vector (SVG), switch the Svg field to a formula and paste the KWGT formula below. It refreshes every minute and draws itself in your widget's exact shape. Set Sizing to Center fit, and the image's width and height to $si(rwidth)$ and $si(rheight)$. In the Touch tab, set the action to open so a tap opens today's log.
